# 🦖 Dino Game

A fun and interactive Dinosaur Game inspired by the classic Chrome Dino offline game. Jump over obstacles, avoid collisions, and try to achieve the highest score!

## 🚀 About the Project

This project is a browser-based Dino Game where players control a dinosaur and jump over obstacles to survive as long as possible.

The game becomes more challenging as the player progresses.

## ✨ Features

- 🦖 Interactive dinosaur character
- 🏃 Smooth jumping animation
- 🌵 Obstacles to avoid
- 🎮 Simple keyboard controls
- 📊 Score tracking
- 💥 Game Over functionality
- 🔄 Restart game option
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open the game in your browser.
2. Press the **Spacebar** or **Arrow Up (↑)** to jump.
3. Avoid the obstacles.
4. Survive as long as possible to increase your score.
5. If you hit an obstacle, the game ends.
6. Restart and try to beat your highest score!
